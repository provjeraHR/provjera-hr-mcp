# sudreg-mcp

MCP server for Croatian company data. Search by name, OIB or MBS from Claude, ChatGPT, Cursor and other AI tools.

MCP poslužitelj za podatke o hrvatskim tvrtkama i udrugama.

## Data sources

A selection of the sources we use, with more added over time:

- Sudski registar RH
- FINA RGFI javna objava (godišnji financijski izvještaji)
- Registar udruga
- e-Oglasna ploča sudova
- APPRRR Baza korisnika potpora
- TED, Službeni list Europske unije
- Registar nesolventnosti
- Nacionalni registar cestovnih prijevoznika
- HANFA, HNB, HAKOM and HERA public registers
- GLEIF LEI registar
- More to come.

Status: in development. Free tier with a monthly limit, paid plans for more.

Data by [provjera.hr](https://provjera.hr). Unofficial, not affiliated with Ministarstvo pravosuđa, FINA or any other source.
